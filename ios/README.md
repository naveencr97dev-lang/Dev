# Auction XI (iOS)

A pass-and-play T20 franchise auction game for 3+ friends on one iPhone.
Bid for real cricketers with a ₹100 Cr purse, then watch your squad play a
simulated league with a result screen after every match, followed by
Qualifier 1, Eliminator, Qualifier 2 and the Final.

SwiftUI, iOS 16+, no third-party dependencies, works fully offline.
Franchise names are fictional; the app is not affiliated with any real league.

## How a game goes

1. **Setup**: 3–10 franchises. Mark each one 👤 Human or 🤖 CPU (CPU teams
   fill out the league). Pick the purse, auction length, bid timer and season length.
2. **Auction**: players come up one at a time (Marquee → Batters →
   All-rounders → Keepers → Bowlers → Uncapped). Each human team has a coloured
   bid button: whoever taps raises the bid. The timer resets on every bid, and when
   it runs out the player is SOLD. CPU teams bid on their own based on player
   value, squad needs and budget. Unsold players come back in an accelerated round.
   - IPL-style increments: +₹5 L under ₹1 Cr, +₹10 L to ₹2 Cr, +₹20 L to ₹5 Cr, +₹25 L above.
   - Squads are 11–18 players with max 8 overseas. A team can never bid so much
     that it can't afford a full XI.
3. **Squads**: every team gets an auto-picked balanced XI (a keeper, 5 bowlers,
   max 4 overseas). Humans can edit their XI at any point in the season.
4. **Season**: single (or double) round robin. Each match plays as a fast
   ball-by-ball ticker (or skip straight to the scorecard). Includes a worm
   chart, full scorecards, Player of the Match, points table with NRR,
   Orange/Purple Cap leaderboards.
5. **Playoffs → Final → Trophy ceremony** with season awards (Orange Cap,
   Purple Cap, MVP, Most sixes, Best buy).

The game saves automatically. Close the app any time and it resumes where you left off.

## Code layout

- `project.yml`: [XcodeGen](https://github.com/yonaskolb/XcodeGen) spec (the
  `.xcodeproj` is generated, not committed).
- `Sources/Engine/`: game rules, Foundation only: auction, CPU bidding,
  ball-by-ball match engine, season/NRR/playoffs, save state.
- `Sources/Store/GameStore.swift`: auction clock, CPU pacing, save file.
- `Sources/Views/`: SwiftUI screens.
- `Resources/players.json`: 273 players with batting/bowling ratings,
  generated by `../tools/build_players.py`.
- `Package.swift` + `Tests/`: lets the engine be tested without Xcode.

### Engine tests

```bash
cd ios && swift test
```

Tests cover the auction rules, valid squads for 3/8/10 teams, a 1,000-match
calibration run (first innings averages ~172, ~6.5 wickets, a six every ~15 balls)
and a full game from setup to champion.

## Getting an installable IPA (no Mac needed)

### Codemagic → Signulous (same as Streaklet)

1. Open **https://codemagic.io**. The `naveencr97dev-lang/Dev` app is already
   connected from Streaklet.
2. **Start new build** → branch **`claude/beautiful-keller-qgp1vc`** →
   workflow **"Auction XI unsigned IPA"** (from `codemagic.yaml` at the repo root).
3. Download **`AuctionXI-unsigned.ipa`** from the build artifacts.
4. Upload it to **Signulous**, sign and install.

> Bundle id: `com.auctionxi.app` (set in `project.yml`). Change it there if
> Signulous needs a different id, then rebuild.

### On a Mac

```bash
brew install xcodegen
cd ios && xcodegen generate && open AuctionXI.xcodeproj
```
