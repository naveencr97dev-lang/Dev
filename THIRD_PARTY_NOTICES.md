# Third-party notices

## Player data

`ios/Resources/players.json` is generated by `tools/players_curated.py`, a hand-made
list of current T20 stars and retired IPL legends. Ratings and traits are this game's
own judgement; career notes are approximate. Player names and career facts are factual
information. Franchise names in this app are fictional and not affiliated with any real
league or team. (Earlier versions derived data from Crick Auction, Apache-2.0; that
data is no longer used.)

## Streaklet

Theme helpers (hex colours, confetti, haptics) and the Codemagic build pipeline
are reused from this repository's own Streaklet app.

## caveman skills

`.claude/skills/caveman/` and `.claude/skills/ultracave/` are copied unchanged
from https://github.com/JuliusBrussee/caveman (v4.1.0, commit 1e91f13), MIT
licensed (see the LICENSE file in each folder). Only the Markdown skills are
included: none of that project's hooks, scripts or proxy.
